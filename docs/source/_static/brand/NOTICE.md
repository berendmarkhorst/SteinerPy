# SteinerPy C2 artwork

These unchanged exports come from the SteinerPy C2 logo kit, prepared on
28 October 2026. The network-tree concept was generated with AI assistance
and reconstructed as vector geometry. The artwork is distributed under the
project's MIT license, included in `LICENSE`.

The wordmark uses outlined Inter Variable lettering from the Inter Project
Authors, licensed under the SIL Open Font License 1.1 (see `OFL.txt`). The SVGs
contain the letter outlines and require no font files or external resources.
The upstream typeface is https://github.com/rsms/inter.

Use the light logo on light backgrounds and the dark logo on dark backgrounds.
The PNG is a fallback for README renderers that cannot display SVGs.
